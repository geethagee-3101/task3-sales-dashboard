# Task 3: Simple Sales Dashboard

## Overview
Created an interactive sales dashboard using Microsoft Power BI Desktop to analyze sales performance.

## Tools Used
- Power BI Desktop
- Sample Superstore Dataset

## Dashboard Features
- Total Sales, Total Profit, and Units Sold KPIs
- Sales by Month
- Sales by Region
- Sales by Product Category
- Month and Region filters

## Deliverables
- Power BI dashboard (.pbix)
- One-page dashboard report (.pdf)
- Dashboard screenshot

## Learning Outcome
Learned to create KPI cards, build charts, use interactive slicers, and present sales insights in a visual format.
